# 质谱字段与规则

sample_id保留前导零。kind取standard、blank、sample、control。area与internal_area为峰面积。level为标样浓度，单位支持ug/L、mg/L、ng/L；统一为ug/L。dilution必须大于0。

每批每检测项至少3个独立浓度点。最小二乘使用Decimal，分母为零拒绝；斜率非正拒绝。空白取同批同项的浓度中位数。净浓度允许为负；不能提前截零。稀释后检出限=0.05×倍数。控制样相对误差超过20%阻断。超过标曲响应范围优先于其他质控判断。

重复编号相同内容标DUPLICATE，不同内容标KEY_CONFLICT。采信包括标曲和空白，最终样品数不等于输入采信数。行数对账独立于样品结果数。

同一批次同一分析项内sample_id唯一；相同样品编号可在不同分析项或批次中复用。

## 方法确认文件（M8）

字段为kind、analyte、nominal、value、unit。kind取blank或spike；blank行nominal为0或空，spike行nominal为加标标示浓度且大于0。单位支持ug/L、mg/L、ng/L，统一为ug/L。每份文件须为单一分析项，至少2个空白平行、最低加标水平至少2个平行；含多个加标水平时仅取最低水平并记警告。

低浓度离散sd_low取空白SD与加标SD的较大者。检出限LOD=空白均值+3×sd_low；暂扣上限=空白均值+3×sd_low×(t95(n-1)/1.645)，平行越少放大越多；定量下限LLOQ=max(空白均值+10×sd_low, 加标均值+t95(n-1)×加标SD)。加标平行不足7次档案为“暂定”，达到7次为“确认”。回收率超出80–120%或RSD超过20%记警告；回收率超出50–150%档案无效，激活须显式force。

常规批次样品按在用档案判定：低于LOD为未检出，[LOD,暂扣上限)为暂扣，[暂扣上限,LLOQ)为检出，达到LLOQ为定量。档案、原始加标与空白记录内容寻址、只插不改；同一确认文件重试不新增档案。切换在用版本时校验前置、单事务提交，失败保留上一版；切换记录载明范围变化（扩大/收窄）、依据与受影响样品。
